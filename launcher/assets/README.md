# OBS startup assistant icon

Approved concept B: charcoal circular badge, white video camera, red accent, and OBS lettering. The PNG was generated with the built-in image generation tool; the ICO contains 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel images. Both are project assets. No separate icon file is required at runtime: the ICO is embedded as an assembly resource and the executable icon.

Generation prompt: Recreate only the selected B camera icon, preserving the charcoal circle, rounded white camera body, right-hand lens, red dot, and bold dark OBS lettering; transparent background, no comparison labels or tray mockups.
